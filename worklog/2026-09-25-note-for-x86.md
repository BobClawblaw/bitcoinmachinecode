# Note for the x86 side: #303 exposes a double close in the boot fill

From the bmc_osx session, 2026-09-25. **Main needs `132c6f7e`** (one file, `asm/daemon/main.c`, 3 lines + a comment).

## What happens

`serve_download_worker`'s boot fill closes a candidate that isn't ready, has `SO_ERROR`, or fails its handshake, but leaves `cfd[i]` set. The cleanup loop right after it closes every `cfd[i]` that didn't become a leg, so those candidates get **closed twice**.

That was harmless until `ad11ac5a` (on main as `1d511676`, #303). `leg_note_installed` now reads the tip block during the fill, for the getheaders-from-pprev recency test. The store's read-fd cache can then open `blkNNNNN.dat` onto a number a failed candidate just freed, and the second `close()` takes it away from the cache. The cache slot keeps the dead number, and the next file opened reuses it. After that, `store_read_at` does its `pread` on blk offsets **from that other file**.

## Evidence (Mac, but the code is shared)

- Signet, with a `close()` watcher in a debug build of the store's fd cache:
  - `CLOSE OF A CACHED READ FD fd=16 -> blk00149.dat`, from the cleanup loop in `serve_download_worker`;
  - then fd 16 pointed to `utxo_run_000005.dat`, and `pread=0 want=443777` at 323,651.
- The apply stopped with `hole/short block (len=-1)` on a block that is fine on disk. The same block read offline returns all 490 KB.
- Mainnet stalled the same way at 968,554 for 12 minutes after a restart.
- If the number had been reused by a **larger** file, the read would have returned wrong bytes instead of failing short.

## x86

x86's store read cache (`bitcoin_store_fast.asm`) caches fd numbers the same way. It is exposed whenever a boot fill has a failed candidate and a tip read lands in between. The trigger is intermittent: on signet it reproduced on the first boot that had a block waiting; after the fix, 3 boots with a block waiting ran clean.

## Fix

In `132c6f7e`, `cfd[i] = -1` goes after each of the three closes, so the cleanup only closes candidates that were never tried.
