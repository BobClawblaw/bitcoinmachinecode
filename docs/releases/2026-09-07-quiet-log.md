# 2026-09-07 — Per-event download lines become per-tick counts; the peer table prints once a minute

Run 13's log carried a line per rotation, window wait, help and failed attempt (540 lines in six minutes from the first two alone) plus the 16-line peer table every ten seconds. Workers now bump counters in the control block and the parent prints one line per tick with this-tick and run totals; the peer table prints every sixth tick; a failed attempt gets a line only at the third in a row on one chunk and every hundredth. Abandons, dead-weight kills, stall kills and rejects keep their lines. Logging only; full gate 0 failures, 8 audits exit 0.
