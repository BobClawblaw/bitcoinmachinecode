# 2026-09-08 — The coinstats history checks itself and rebuilds itself

The history build died in pass 3 when the box went over its memory at 19:05Z. Nothing noticed: `gettxoutsetinfo` below the live index's seed kept answering "needs the history build", mempool.space's block indexer died on the first such height, and 209 GB of scratch sat beside the archive, in files a rerun would have APPENDED to. The build wrote its rows straight into the file the daemon appends to, so a death in pass 4 would have left half a history with no marker.

- **Two files.** The builder writes `coinstats_hist_base.dat` (rows 0..to_height) to a temp name and renames it into place with a completion flag and a hash over every row's checksum, written last after an fsync. The live index keeps its tail in `coinstats_hist.dat` as before. The reader prefers the base for every height it covers, pairs a tail row with the tail's own predecessor so the height right above the base keeps its block_info, and reopens the base when its inode changes.
- **Detect.** Once a heartbeat the fold worker checks the base: the header every time; every row, the header's hash and the seam (the set's counters and the MuHash digest at the tail's first height, two independent computations) the first time and after every rebuild. A base that fails is renamed `*.broken-<epoch>` so every process sees it absent.
- **Repair.** A missing base spawns `bmc_build_coinstats_hist` beside the daemon's executable, niced, with the chain in its environment; never during initial block download, never while another builder holds `csh_tmp/lock`, three attempts per boot with six hours between them. Completion is the file, not the exit status (SIGCHLD is ignored in the worker). `bmc.coinstatshistrepair=0` leaves it to the operator; `bmc.coinstatshistworkers` sets the worker count (0 = cores/4, 2..8).
- **The builder resumes.** Each pass writes `csh_tmp/passN.done` (its worker count and target height); a rerun skips the passes whose markers match. Scratch without a marker, and the old layout's `csh_*.tmp`, is discarded first. Pass 3 sizes its concurrency from MemAvailable and the largest range on disk, whatever was asked for. A retried pass 2 empties its append-mode range files first.
- **Status.** The refusal text names the state ("being rebuilt", "waits for initial block download", "failed 2 times, next attempt in ..."); the worker writes the same line to `coinstats_hist.status` for the RPC parent.

`test_coinstats_hist_build`: the base and its check; a dead run's leftovers (an old-layout range file and unmarked scratch carrying a bogus removal) are discarded and the digest equals the clean build's; stop-after-pass-1, resume at pass 2, resume at pass 3, same digest; another target height starts over; a flipped byte makes the row "no record" and the check quarantines the base naming the row; a wrong header hash and a missing complete flag are rejected; the supervisor with stub builders: disabled, in IBD, spawn, three failures with backoff then give up, a new boot rebuilds and verifies, a held lock means wait. `test_coinstats_hist`: a base beneath a live tail, the seam agreeing, height 102 keeping its block_info, a base that disagrees at the seam quarantined by height. **Watched to fail** against the pre-change builder: 22 assertions.
