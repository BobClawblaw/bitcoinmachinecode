# ARM port worklog — 2026-08-24

Campaign: port the x86-64 assembly Bitcoin node (github.com/BobClawblaw/
bitcoinmachinecode) to AArch64 so it builds + runs NATIVELY on this box
(DGX Spark / GB10, Ubuntu 24.04, `aarch64`), then sync the blockchain live.

Branch: `arm-port` (long-lived, merges `origin/main`). See port/ARM_PORT.md.

## Environment
- uname -m = aarch64, 20 cores, NVIDIA GB10.
- Native toolchain = host gcc (`aarch64-linux-gnu-gcc`). No emulation anywhere.
- Repo is 100% x86-64 NASM asm (SysV AMD64 ABI, SHA-NI) + C daemon.
- ARM64 syscall numbers differ from x86-64 (read=63 write=64 close=57
  socket=198 connect=203 setsockopt=208; `svc #0`, number in x8).

## Method (per module)
Read upstream asm/<name>.asm for the exact ABI/semantics -> write
port/arm64/<name>.S (AAPCS64, same exported symbols so the shared C harnesses
and daemon link UNCHANGED) -> build native -> run the repo harness -> plus
differential fuzz against Python hashlib / big-int oracles. Only DONE after
the repo's own harness + differential fuzz pass natively.
